# 導覽改版 v2 驗證說明（給 Antigravity）

對象：分支 `feat/onboarding-v2`（PR 見 GitHub）。規格：`docs/onboarding-v2-spec.md`。
你的工作是**驗證，不是修改**。發現問題時記錄下來，不要改程式。

## 0. 準備

```bash
git fetch origin && git checkout feat/onboarding-v2
uv run --project app pytest tests -q
uv run --project app --with playwright pytest tests/ui --ui -q     # 連跑 3 次
uv run --project app python -m dataprocessor                       # 或 run.sh / run.bat
```

- 每次手動驗證前清掉瀏覽器的 localStorage 與 sessionStorage（或用新的無痕視窗），除非該項要求保留進度。
- 視窗大小：預設 1440×900；標明的項目另外用 1100×800、1000×700。
- 每個項目截一張圖，檔名用項目編號（例如 `B3.png`）。

## C. 關卡 A（核對一份資料，10 步）

從歡迎畫面「用範例資料邊做邊學」開始，照指令條操作。

| # | 操作 | 通過標準 |
|---|---|---|
| C1 | 走完第 1～7 步 | 進度顯示「n/10」 |
| C2 | 第 8 步「把配對做完」 | 子步驟依序指到每一筆剩下的配對（確認正確或沒有配對）；做完後 Match 卡片不是橘色、配對分頁的需處理是 0 |
| C3 | 第 9 步，用「確認無誤，下一筆」 | 提醒行的「還有 n 列」每處理一列就減 1；遇到一定要處理的警示時，浮標改指那個警示，提醒寫怎麼處理；最後進度顯示「都已處理，可以下載」 |
| C4 | 在第 9 步完成**前**按「下載 Excel」 | 出現 ⚠「還有 n 列沒看，看完再下載」，步驟不前進 |
| C5 | 第 10 步下載 | 檔名以「示範_」開頭；出現完成狀態，主要按鈕是「練習進階功能」 |
| C6 | 第 8 步做到一半重新整理，從「說明 ▾」繼續 | 自動準備範例資料，停在第 8 步的下一個未處理子步驟 |
| C7 | 選錯（例如第 8 步按了「選這筆」以外的按鈕、第 9 步亂改值） | 有 ⚠ 提示寫看到什麼、怎麼改；修正後能繼續 |

## D. 進階功能 mission（6 條）與實地練習（5 個）

從「說明 ▾ → 練習中心」逐一開始。**每一條都要做到完成畫面**。

| # | 項目 | 通過標準 |
|---|---|---|
| D1 | 看這一格是怎麼來的 | 每一步都有提示；最後看到處理過程；完成畫面出現 |
| D2 | 兩張表並排，找配對的答案 | 原始資料左右並排；最後 INV-1008 為確認沒有 |
| D3 | 一次確認很多筆 | 勾選後確認；切到「已處理」看得到紀錄 |
| D4 | 清掉重來，按錯可以復原 | 第一次按顯示數量、第二次清除、復原後數量回來 |
| D5 | 表格太寬，搬到另一個螢幕 | 新視窗開啟；在新視窗選列，主視窗同步；Pop in 後回到主視窗 |
| D6 | 用公式算出新欄位 | 看到「換算台幣」與 SQL 原文 |
| D7 | 5 個實地練習（排除、對照、配對、取值、驗證） | 故意寫錯一次，看到「哪一列、抓到什麼、應該是什麼」；修正後全部打勾 |
| D8 | 每條最後一步 | 沒有「下一步」可以跳過 |
| D9 | 完成畫面的「下一個」 | 開的是清單順序中第一個還沒練過的項目 |
| D10 | 說明卡 | 主要按鈕是「開始練習」；沒有只指過去就結束的「試試看」「帶我去」 |

## E. 練習中心

| # | 操作 | 通過標準 |
|---|---|---|
| E1 | 三個入口：關卡 A 完成畫面、「說明 ▾ → 練習中心」、關卡 A 完成後的歡迎畫面 | 都能打開練習中心 |
| E2 | 練過幾項後打開 | 練過的有 ✓ 與「再練一次」；右上「已練 n / 11」正確 |
| E3 | 看推薦項目 | 整個清單只有一個藍色主要按鈕，是第一個沒練過的 |
| E4 | 1000×700 打開 | 改成一欄，整個對話框在畫面內，可以捲到最後一項 |
| E5 | 完成關卡 A 後，用範例以外的 Excel 自己執行一次 | 出現一次「看完這份資料後，可以到說明 ▾ 練習進階功能」；按「不用了」後再執行不會出現 |
