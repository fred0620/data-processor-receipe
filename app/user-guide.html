資料處理器使用手冊

把 Excel 裡的原始資料，依照 recipe 整理成可以交出去的資料表。有疑慮的地方會標記出來，你在畫面上確認、修正後再下載。全部在你的電腦上執行，資料不會上傳到任何地方。

  • 1. 安裝與啟動
  • 2. 操作說明
  • 3. 檔案與資料安全
  • 4. 常見問題

1. 安裝與啟動

第一次安裝

不需要先安裝 Python，工具會自己準備。

步驟一：取得工具。 到公司 GitLab 專案的 Releases 頁，下載最新的 data-processor-版本.zip。

步驟二：解壓縮。 解壓到固定位置，例如 文件\data-processor。不要在壓縮檔裡直接執行。

從瀏覽器下載的 ZIP 要先解除封鎖再解壓，不然雙擊 run.bat 可能跳出安全性警告或沒有反應。步驟見換版說明第 2 節。

步驟三：啟動。

  • Windows：雙擊 run.bat。
  • macOS：開啟終端機，進入資料夾後輸入 bash run.sh。

第一次會自動下載 uv 和 Python，約 1 到 3 分鐘。套件已經附在 ZIP 裡，不需要連到 PyPI。完成後瀏覽器會自動開啟工具。

啟動後，工具資料夾會長這樣：

記住一件事就好：你的資料都在 workspace。app 是程式本身，每次更新都會整包換掉，不要在裡面放自己的檔案。

全部都在這個資料夾內，電腦上原本的 Python 不受影響，也不會改動系統設定。不想用了，刪掉整個資料夾就好；要保留資料的話，先備份 workspace。

之後每次使用

雙擊 run.bat 就好。那個黑色視窗就是工具本身，使用時不要關掉。

用完時，關閉瀏覽器頁面或黑色視窗都可以。關閉頁面約 10 秒後，工具會自動結束。工具已經開著時再雙擊 run.bat，只會開啟原本的頁面，不會多開一個。

工具右上角的「使用手冊」連結可以隨時開啟這份手冊，左上角顯示目前的版本號。

更新與退回版本

更新到新版、新版有問題時退回，都寫在 換版說明，有圖解。換版不會動到 workspace 裡的資料。

公司電腦不能連網，或擋 GitHub

套件已經附在 ZIP 裡，只有第一次的 uv 和 Python 需要從 GitHub 下載。如果公司擋 GitHub：

  1. 在一台能連網的 Windows 64 位元電腦上解壓 ZIP，雙擊 run.bat 一次，讓它下載完成。
  2. 把整個資料夾複製到目標電腦，但不要複製 runtime\venv、runtime\cache 和 workspace。
  3. 雙擊 run.bat，工具會直接使用複製過來的檔案，全程不連網。

2. 操作說明

什麼是 recipe

recipe 是一份文字檔，寫好「資料怎麼讀、哪些列不要、怎麼配對、代碼怎麼對照、輸出哪些欄位」。不同的資料用不同的 recipe，工具本身不用改。第一次啟動時會附一份範例 recipe 和範例資料，可以先試跑看看。

請 AI 寫 recipe

  1. 按左邊 Recipe 的「新增」，再按「複製規格給 AI」。
  2. 把規格貼給你的 AI，再說明你的資料和規則：有哪些工作表、欄位叫什麼、哪些列不處理、兩張表用什麼對、對不到時改用什麼、代碼要轉成什麼、最後要輸出哪些欄位。
  3. 把 AI 寫好的 recipe 貼回「新增」的視窗，按「下一步：確認說明」。工具會把 recipe 寫成「每一列資料會經過哪些判斷」：先排除什麼、先用什麼找、找不到改用什麼、找到多筆怎麼辦、最後檢查什麼。確認都符合你的規則再按「確認並儲存」。之後在 recipe 下方按「查看」也可以再看一次說明。
  4. 有問題時視窗會列出所有問題，按「複製問題給 AI」，貼回去請它修正，再貼一次。

不要把真實資料貼給外部的 AI。用欄位名稱和幾列假資料說明就夠了。

處理一份資料

  1. 在左邊選 recipe。
  2. 選擇或拖曳 Excel 檔（.xlsx）。
  3. 按「執行」。

表格太寬、想看完整內容時，按分頁列右邊的「Pop out ↗」，目前這個分頁會搬到另一個視窗，可以拖到另一個螢幕、放到最大，照常處理。搬出去的分頁在主視窗會標上 ↗，點進去只有一行說明，不會兩邊各顯示一份；其他分頁照常在主視窗使用，所以可以一個螢幕看結果、另一個螢幕處理配對，兩邊的修改即時同步。在一個視窗按「前往配對」之類的連結，會交給擁有那個分頁的視窗顯示。看完按 pop out 視窗右上角的「Pop in」，篩選和選到的列會一起帶回主視窗；或在主視窗按「全部 Pop in」。

檢查的流程：執行完會直接打開第一筆需檢查的列，細節在右邊。看完按細節下方的「確認無誤，下一筆」（只會確認「要人判斷」的警示，例如金額不一致；「不在對照表」、「找不到配對」、「讀不懂」、「必填空白」要先處理，這時按鈕會變成「還有 n 個要處理」和「跳過」；真的沒問題時可以在那個警示上個別按「確認無誤」），或用 J／K（↓／↑ 按鈕）在列之間移動；上方的進度條顯示已經處理了幾列。全部處理完會顯示「都已處理，可以下載」。在欄位裡打字時 J／K 不會換列。

找不到原因時，可以回到上傳的 Excel 核對原本寫的是什麼： - 欄位名稱下方的儲存格位置（例如 E6）會在旁邊跳出小卡，顯示表頭、那一列和前後兩列，並把原始寫法和整理後的值並排，不離開正在檢查的列。 - 細節最下方的「原始 Excel」列出這一列來自哪幾張表的哪一列，配對卡片與排除的列旁邊也有表格圖示，點了一樣跳出小卡。 - 小卡上的「完整工作表」打開「原始資料」分頁，照 Excel 的欄名與列號顯示整張工作表，標出那一列與那一格，右邊的細節留著，可以邊看邊改。這一列有配對到另一張表時，會自動左右並排：左邊是這一列自己的表，右邊是配對到的表，兩邊都標出對應的那一列。按 Esc 或點小卡外面就會關掉小卡。 - 在「原始資料」分頁打開「左右並排」，就能把兩張工作表放在左右兩邊比對，例如發票明細和報關單。兩邊各自從工作表名稱旁的選單選工作表、跳到某一列、翻頁；「左右交換」對調兩邊，右邊的叉叉關掉並排。 - 原始表在列號旁邊有配對欄，這張表參與幾個配對就有幾欄，欄名是對面那張表（例如發票明細有「報關單」和「匯率表」兩欄）；對著另一邊那張表的那一欄，欄名會加粗： - 已配對的列文字淡化，寫著配到對面的第幾列（例如「→ 4」，配到三列以上寫「← 7 列」），按一下就在另一邊打開那一列，自己這一列也會標出來；只有一張表時會自動打開並排。 - 配到好幾列時（例如一列匯率配到七張發票），對面配到的列都會淡淡標出，上方寫「第 1／7 筆」；再按一下同一個連結就換到下一筆。 - 要處理的列標橘色：「找不到」（這一列沒有配到）、「沒用到」（對面沒有任何一列配到它）、「候選」與「n 筆候選」（要選一筆）、待確認的配對。 - 「已排除」是篩選掉、不參與配對的列。 - 上方依每個配對寫著還有幾列要處理。左邊找不到配對時，看右邊還「沒用到」的列，通常就是答案。 - 想放到另一個螢幕看，就在「原始資料」分頁按「Pop out」。搬出去的視窗一樣能切換工作表、左右並排；並排的狀態會一起帶過去，Pop in 時也會帶回來。這時從主視窗按「完整工作表」，會交給那個視窗顯示，主視窗留在正在檢查的列。

版面可以調整：拖曳左欄或右側細節的邊界改變寬度，連按兩下恢復預設，按左上角的「‹」收起左欄。調整過的寬度會記住。配對卡片預設只顯示比對用的欄位，每張卡片下方可以各自「顯示全部欄位」，上方的「顯示全部欄位」開關一次展開所有卡片。結果表的「換行」、「緊湊」與要顯示的欄位在「檢視」選單裡。「不在對照表」可以直接在細節裡選對應值補上，不用離開正在檢查的列。

上方的八張卡片是每個步驟的摘要。綠色是沒問題，橘色是需要你檢查，藍色是你已經確認或修改過的。點一下卡片可以看細節，按「查看」直接跳到相關的列：讀到哪個工作表、排除幾列、哪些格子看不懂、配對了幾列、驗證找到幾個問題。橘色代表有需要檢查的地方，紅色代表無法執行（通常是找不到必要的欄位，畫面會說明原因）。

檢查與修正

  • 結果：預設只顯示需要檢查的列。橘色底的格子有問題，滑鼠停在上面可以看原因；灰色斜體是看不懂的原始內容。點一列會在右邊打開細節，可以直接修改，按 Enter 儲存。欄位太多時，用「欄位」隱藏不需要看的欄位；「緊湊」可以讓一個畫面看到更多列。修改會保留原值，按「還原」可以改回來。想知道某一格怎麼來的，把滑鼠移到欄位名稱上按「怎麼來的」；想看整列的經過（配對試了哪些方式、檢查有沒有過），展開「這一列的處理過程」。
  • 配對：列出找不到、待選擇、需要確認的配對，左右並列比較，相同的欄位標綠、不同的標橘。預設只顯示比對用到的欄位，按「顯示全部欄位」看完整內容。可以「選這筆」、「手動指定」、「沒有配對」，或在配對正確時按「確認正確」。一對多、多對多的配對可以「加入」或「移除」多列。
  • 對照表：列出對照表裡沒有的寫法（例如「陸運」），選好對應值按「儲存」。清單裡沒有合適的值，選「新增對應值」自己輸入。之後處理其他檔案也會自動套用；補錯了可以在「已補上的對照」移除。
  • 排除：被篩掉的列與原因。
  • 所有警示：全部的問題，可以勾選後一次「確認無誤」。驗證規則的警示會直接列出相關欄位現在的值（例如「金額 2,000　報關金額 2,100」），不用點開就能自己算算看；修改後重新執行，顯示的也是新的值。想看規則用到的全部欄位（例如總價、單價、數量），在細節的警示上按「怎麼判斷的」，會展開「這一列的處理過程」並標出那條規則：白話的規則，以及這一列每個用到的欄位的值。

你做的修改、指定的配對、確認過的警示都會記下來。同一份 recipe 加上內容相同的 Excel，關掉重開或重新上傳都會套回去，突然關掉也不會遺失。想從頭再檢查一次，按右上角的「重新檢查」：第一次按會顯示要清掉幾項，再按一次才清除；清完畫面下方會出現「復原」，按錯可以救回來。補上的對照表不會被清掉，因為其他檔案也在用，要到「對照表」分頁個別移除。處理過的警示不會消失，會變成藍色並寫上怎麼處理的（已人工修改、已補對照、已人工配對、已確認），在「所有警示」選「已處理」或單列細節的「處理紀錄」都看得到。同一份檔案重新執行，或 recipe 修改後再執行，這些決定都還在。

下載

按右上角「下載 Excel」。檔案裡有：

工作表 內容
整理結果 輸出的資料，加上檢查狀態、問題說明、來源列；有問題的格子有底色，人工修改的格子有註解寫原值
待檢查 所有警示
配對明細 每一列用哪個方式配到哪一列
排除 被篩掉的列
對照待補 還沒補上對照的寫法

下載的檔案也會在 workspace/output 留一份。

3. 檔案與資料安全

資料夾 內容
workspace/output 匯出的檔案
workspace/recipes 你的 recipe
workspace/mappings 在畫面上補的對照
workspace/reviews 你的修改、指定的配對、確認過的警示
workspace/samples 範例資料
workspace/uploads 上傳到工具的暫存複本，結束時清除
workspace/logs 操作與錯誤紀錄，不記檔名和資料內容

工具只接受本機（127.0.0.1）的連線，其他網站無法透過瀏覽器讀取或操作工具裡的資料。遇到錯誤時，畫面只顯示一般訊息，詳細原因寫在 workspace/logs/app.log，回報問題時附上這個檔案即可。匯出的檔案不會自動清除，請依公司規定保管。

4. 常見問題

顯示「無法下載 uv」或「環境建立失敗」 通常是公司網路阻擋 GitHub，請改用第 1 節的離線安裝。

安裝到一半中斷 重新執行 run.bat 會接續完成。還是失敗時，刪除 runtime 資料夾再試一次。

瀏覽器沒有自動開啟 看黑色視窗裡顯示的網址，例如 http://127.0.0.1:8765，貼到瀏覽器。

畫面顯示「工具已經關閉」 黑色視窗被關掉了。重新執行 run.bat，再重新整理頁面。

更新後有問題 執行 run.bat rollback 退回上一版，並把版本號和 workspace/logs/app.log 回報給負責人。詳細步驟見換版說明。
